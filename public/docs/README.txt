PUT THE ARTICLES AND MUSINGS IN THIS FOLDER (public/docs)

Each button on the Writings page (and on the home page) opens one file from here.
The file name must match EXACTLY, including capital letters and the ending (.docx / .pdf / .doc):

  AMI-Magazine-Rav-Dovid-Oppenheim.pdf
  Crown-Jews-Mishpacha.docx
  Hamodia-article.docx
  Luggage-vs-Baggage.doc
  The-Chosen-People.docx
  When-being-Wrong-is-being-Right.docx
  A-Gravestone-Worth-Noting.docx
  Kol-The-Concept-of-Sound.docx
  OVERLOOKING-A-GRIEVANCE.docx
  PRAYER.docx

If your file has a different name or ending (for example a .pdf instead of a .docx), either rename the file to match,
or open src/content/writings.js on GitHub and change that line to match your file.
To add another article: upload the file here, then add one line to src/content/writings.js:  ["Title shown on the button", "/docs/Your-File-Name.docx"],
